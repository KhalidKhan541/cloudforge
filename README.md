## ✨ Features

### Infrastructure Management (20+ pages)
- 📊 **Dashboard** — Real-time infrastructure overview
- 🔍 **Monitoring** — CPU, memory, disk, network metrics with charts
- 🚨 **Alerts** — Configure and manage alert rules
- 🖥️ **Servers** — Provision, manage, and monitor virtual servers
- ☸️ **Kubernetes** — Cluster management, deployments, events
- 🗄️ **Databases** — PostgreSQL, MySQL, Redis, MongoDB, Elasticsearch
- 📦 **Object Storage** — S3-compatible storage buckets
- 🌐 **CDN** — Content delivery network zones
- 🔗 **DNS** — DNS record management
- ⚖️ **Load Balancers** — Traffic distribution and health checks
- 🛡️ **Firewall** — Security rules and DDoS protection
- 🔄 **CI/CD Pipelines** — Build, test, deploy automation
- 🐳 **Container Registry** — Docker image management
- 📝 **Logs** — Real-time log streaming
- 💻 **Terminal** — Web-based SSH terminal
- ⚡ **Functions** — Serverless compute
- 🛒 **Marketplace** — One-click app deployment
- 👥 **Team** — Multi-role access control
- 🔑 **API & Webhooks** — RESTful API access
- 💳 **Billing** — Subscription and usage tracking
- ⚙️ **Settings** — Account and security settings

### Platform Features
- 🌙 Dark / Light / System mode
- 🎨 White-label ready (CSS variable theming)
- 📱 Fully responsive
- 📊 Real-time metrics and charts
- ⚡ No database required (mock data)
- 🧩 Modular architecture

## 🚀 Getting Started

```bash
git clone https://github.com/KhalidKhan541/cloudforge.git
cd cloudforge
npm install
npm run dev
```
